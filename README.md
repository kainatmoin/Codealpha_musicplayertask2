# Music Player Web App

A responsive music player built using **HTML**, **CSS**, and **JavaScript**. The application allows users to play, pause, skip, and switch between multiple songs through a simple and interactive user interface.

---

## Project Overview

This project demonstrates the development of a browser-based music player without using any external frameworks. It uses the HTML5 Audio API to provide music playback functionality.

---

## Features

- Play and pause music
- Next and previous track controls
- Playlist support
- Audio progress bar
- Song title display
- Responsive user interface
- HTML5 Audio API integration

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any modern web browser.
3. Select a song from the playlist.
4. Use the playback controls to play, pause, or switch tracks.
